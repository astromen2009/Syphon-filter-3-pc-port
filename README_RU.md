# Syphon Filter 3 PC

[English](README.md) | [Español](README_ES.md) | Русский

Версия 0.9.0, Windows 10/11, 64 бит.

Проект запускает оригинальный Syphon Filter 3 для PlayStation (исполняемый файл `SCUS_946.40` с американского диска) и отрисовывает его родным рендерером ПК. Логика игры не изменена: ИИ, миссии, бои и анимации остаются оригинальными. Меняются изображение, управление и есть несколько дополнений.

Нужна собственная копия игры (диск USA в виде `.bin` + `.cue`). Файлы игры сюда не входят.

## Возможности

- Любое внутреннее разрешение, сглаживание MSAA/SMAA и широкий экран Hor+.
- PGXP: вершины не дрожат, текстуры не искажаются, есть настоящий буфер глубины.
- Игра идёт с оригинальной скоростью в отдельном потоке, а изображение интерполируется под частоту монитора.
- Переделанный прицел AU300. Рентгеновский вид теперь рисует настоящую сцену той же камерой: видит сквозь стены, совпадает с видом снаружи, работает без задержки, а персонажи и их оружие зелёные, как на PS1.
- Освещение сцены, вспышки выстрелов освещают комнату, дым, кровь, стекло, искры, следы пуль, снег и пар дыхания в холодных миссиях, ночное видение как в оригинале.
- Прицеливание мышью 1:1, настраиваемые клавиатура и геймпад, второй игрок для режима на двоих.
- Банк оружия: любое оружие можно взять в любую миссию, с моделью, фото и звуком (чит «Всё оружие»). Добавлено оружие из Syphon Filter 1 и 2: огнемёт, пулемёт Гатлинга, ручной шокер и дробовик Страйкер.
- Язык текста и язык голосов выбираются отдельно: английский (оригинал), испанский (текст, голоса и звук роликов) и русский (текст и озвучка).
- Лаунчер для Windows, меню настроек ПК (F12), карта памяти в виде файлов, видео главного меню в высоком качестве, новые персонажи в мини-игре и режиме на двоих.

Полный список в [FEATURES_RU.txt](FEATURES_RU.txt).

## Как играть

1. Положите диск USA (`.bin` + `.cue`) в папку, например `SYPHON3\`.
2. Скопируйте туда проект, например в `SYPHON3\SF3_PC\`.
3. Запустите `bin\sf3_nativo.exe`. Он ищет диск в своей папке и в папках выше.

Разрешение, язык, управление и остальное настраиваются в лаунчере. В игре F12 открывает настройки ПК (там же читы: открыть всё, неуязвимость, всё оружие, невидимость), Esc открывает меню паузы игры, Alt+Enter переключает полноэкранный режим.

## Дополнительные данные

Некоторым функциям нужны данные, которых нет в этом репозитории. Их кладут рядом с exe или в одну из трёх папок выше.

| Файл | Содержимое |
|---|---|
| `idiomas.pak` | Испанский и русский текст и голоса, испанский звук роликов |
| `armas.pak` | Модели, текстуры, значки, фото, звуки и настройки (`armas.txt`) дополнительного оружия |
| `personajes\` | Дополнительные персонажи для мини-игры и режима на двоих |

Если у вас есть отдельные файлы (`textos_es.pak`, `voces_es.pak`, `videos_es_*.pak`, `voces_ru_*.pak` и папка `armas`), `bin\CREAR_PAKS.bat` соберёт их в `idiomas.pak` и `armas.pak`. Отдельный файл с тем же именем всегда важнее файла внутри пакета.

## Папки

```
bin/                 готово к игре: sf3_nativo.exe, SDL2.dll и утилиты
source/
  apps/sf3_nativo/   окно, рендерер, меню, лаунчер
  src/, include/     эмуляция R3000, GPU/SPU/CD, диск и форматы
  third_party/       PsyCross, pl_mpeg, stb_vorbis
  data/recursos.bin  сжатые картинки и звуки меню
  build.sh           скрипт сборки
```

## Сборка

Проект собирается Clang. Для Windows используется [llvm-mingw](https://github.com/mstorsjo/llvm-mingw), он работает и из Linux:

```bash
cd source
SDL2_DIR=/путь/SDL2/x86_64-w64-mingw32 \
OPENAL_INCLUDE=/путь/openal-soft/include \
LLVM_MINGW=/путь/llvm-mingw \
./build.sh win
```

Нужны файлы разработки SDL2, заголовки OpenAL Soft (их использует PsyCross) и Python 3 (для встраивания `data/recursos.bin`). `./build.sh linux` собирает версию для Linux.
